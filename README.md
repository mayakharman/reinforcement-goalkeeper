# מעבדת השוער הלומד — Reinforcement Learning Goalkeeper Lab

**סטודנטית:** מאיה חרמאן (Maya Kharman)
**קורס:** יישומי בינה מלאכותית בעולם העסקי

אתר אינטראקטיבי (חזית בלבד — HTML / CSS / JavaScript, ללא שרת) שמלמד את הרעיון של
**למידה מחיזוקים (Reinforcement Learning)** דרך משחק בעיטות פנדל: שוער וירטואלי
("הסוכן") לומד בהדרגה, מתוך ניסוי וטעייה מול תגמולים, איזה כיוון כדאי לקפוץ
אליו — בדיוק כפי שסוכן RL אמיתי לומד מדיניות (policy) ממקסום תגמול מצטבר.

## מה זה למידת חיזוק (Reinforcement Learning) בקצרה

למידת חיזוק היא גישת למידה שבה **סוכן (Agent)** לומד להחליט על ידי אינטראקציה
עם **סביבה (Environment)**, ולא על ידי קבלת התשובה הנכונה מראש. בכל צעד הסוכן
בוחר **פעולה (Action)** בהתאם ל**מצב (State)** הנוכחי, מקבל **תגמול (Reward)**
מספרי על התוצאה (חיובי או שלילי), ומעדכן את אסטרטגיית ההחלטות שלו כדי למקסם את
**התגמול המצטבר** לאורך זמן. השילוב בין **חקירה (Exploration)** — ניסיון
אקראי לגלות מידע חדש — לבין **ניצול (Exploitation)** — שימוש במה שכבר נלמד —
הוא בליבת כל שיטת RL.

## מה זה Q-Learning בקצרה

Q-Learning היא שיטת RL "טבלאית": לכל שילוב של מצב ופעולה נשמר ערך מספרי (Q)
המעריך כמה משתלמת הפעולה הזו במצב הזה. אחרי כל צעד, הערך מתעדכן לפי הנוסחה
הקנונית:

```
Q(s,a) ← Q(s,a) + α · [ r + γ · max(Q(s′,·)) − Q(s,a) ]
```

כאשר `α` הוא קצב הלמידה, `γ` הוא משקל התגמול העתידי, ו-`r` הוא התגמול שהתקבל.
בפרויקט הזה יש 9 מצבים (כיוון הבעיטה הקודמת × מגמת הבועט/ת) ו-3 פעולות
(שמאלה / מרכז / ימינה), כך שכל טבלת ה-Q ניתנת להצגה מלאה על המסך — ראו את
[`PROJECT_PLAN.md`](./PROJECT_PLAN.md) להסבר המלא על הבחירה בשיטה זו.

## למה זה מדגים RL בצורה נכונה

| מושג תיאורטי | מימוש בפרויקט |
|---|---|
| Agent | השוער הוירטואלי (טבלת Q-Learning) |
| Environment | מגרש, שער, הבועט/ת וכיווני הבעיטה |
| State | היסטוריית הבעיטות האחרונות + מגמת הבועט/ת |
| Action | קפיצה שמאלה / מרכז / ימינה |
| Reward | \u200E+1 על הצלה, \u200E-1 על גול |
| Learning | עדכון טבלת Q לפי כלל Q-Learning ומדיניות ε-greedy |
| Goal | מקסום התגמול המצטבר לאורך זמן |

## הרצה מקומית

הפרויקט טוען את `js/app.js` כ-ES Module, שמייבא בעצמו את שאר קבצי ה-JS. **פתיחת
`index.html` ישירות מהדיסק (לחיצה כפולה, `file://`) לא תעבוד** — דפדפנים חוסמים
ייבוא מודולים כאלה מסיבות אבטחה (CORS). יש להריץ שרת סטטי מקומי:

### אפשרות 1: Live Server ב-VS Code (מומלץ)

1. התקינו את התוסף **Live Server** (מאת Ritwick Dey) מתוך VS Code Extensions.
2. לחצו קליק ימני על `index.html` בסייר הקבצים.
3. בחרו **Open with Live Server**.
4. האתר ייפתח בדפדפן בכתובת כמו `http://127.0.0.1:5500`, ויתעדכן אוטומטית בכל שמירה.

### אפשרות 2: שרת סטטי מהטרמינל

```bash
python3 -m http.server 8000
```

ואז פתחו `http://localhost:8000` בדפדפן.
